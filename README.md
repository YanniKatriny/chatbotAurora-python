# Chatbot Aurora de escolhas em Python

## O que faz
Um chatbot que simula a apresentação para terapeutas holísticos e integrativos interessados em conhecer mais sobre o site da SoulAurora, seus benefícios, planos/preços, como ele funciona e como pode ajudar o terapeuta. O usuário escolhe opções em um menu numerado e o chatbot responde de acordo com a escolha

## Como rodar
python ChatbotAurora.py

## O que aprendi
- Separei o código em funções de acordo com cada menu principal e cada opção de escolha. 
- Usei o if/ elif/ else para algumas opções. 
- Tratei erros quando o usuário digita uma opção incorreta ou que não existe. 

## Exemplo de uso
```
AURORA: Olá! Eu sou a Aurora, assistente de atendimento da plataforma Soul Aurora, feita para apoiar terapeutas integrativos e holísticos que buscam estruturar e expandir a própria prática.

AURORA : Antes de começarmos, me diga seu nome?
Yanni

AURORA: Prazer, YANNI! De acordo com o que mais pesa para você, entenda como a Aurora pode te ajudar.
1 - Estou começando agora
2 - Transição de carreira sem clientes
3 - Dificuldade em atrair clientes
4 - Dificuldade em organizar meus atendimentos
ESCOLHA UMA OPÇÃO:
```
